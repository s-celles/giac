# GIAC — Computer Algebra System Library

GIAC is a C++ library for symbolic and numeric computation (Computer Algebra System).

- [English homepage](http://www-fourier.ujf-grenoble.fr/~parisse/giac.html)
- [French homepage](http://www-fourier.ujf-grenoble.fr/~parisse/giac_fr.html)
